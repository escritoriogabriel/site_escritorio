# Gabriel Corrêa Advocacia

Site institucional estático publicado no GitHub Pages.

## Páginas públicas

A página inicial concentra as seis áreas de atuação do escritório: Direito do Trabalho, Direito de Família, Direito Criminal, Servidores Públicos, Concursos Públicos e Licitações. O site também mantém as páginas institucionais Sobre e Contato.

## Estrutura principal

- `index.html`: página inicial e apresentação das áreas de atuação.
- `sobre.html`: história, princípios e áreas do escritório.
- `contato.html`: canais de atendimento e localização.
- `*.html`: landing pages das seis áreas exibidas na Home.
- `assets/css/`: estilos do site e das landing pages.
- `assets/js/`: comportamentos das landing pages e widget de atendimento.
- `assets/img/`: imagens usadas nas páginas públicas.

O conteúdo editorial legado, páginas antigas, geradores e assets sem referência no site público foram removidos para manter o repositório enxuto e coerente com a navegação atual.
